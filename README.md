# Telco Churn — Reproducible Data Project

## Overview

This project establishes a reproducible data science environment for the Telco Customer Churn dataset as part of the ESILV MLOps course.

The objective of this first practical assignment is to create a structured project, manage its Python environment, inspect the source dataset, and generate a report describing its contents and integrity.

## Project Structure

```text
telco-churn/
├── data/
│   └── raw/                  # Original dataset (not tracked by Git)
├── reports/
│   └── data_overview.json    # Generated data inspection report
├── references/               # Documentation and data references
├── telco_churn/
│   └── dataset.py             # Dataset loading and inspection
├── pyproject.toml             # Project configuration and dependencies
├── uv.lock                    # Locked dependency versions
├── .gitignore
└── README.md
```

## Requirements

- Python 3.12
- [uv](https://docs.astral.sh/uv/)

## Environment Setup

Clone the repository and navigate to the project directory:

```bash
git clone <repository-url>
cd telco-churn
```

Create the environment and install the locked dependencies:

```bash
uv sync --locked
```

The raw dataset must be available at:

```text
data/raw/datasets.csv
```

The dataset is intentionally excluded from Git to preserve the original source file and avoid committing raw data.

## Source Dataset

The original CSV file is not tracked by Git. Obtain the Telco Customer Churn dataset from the source specified by the course materials and place it at `data/raw/datasets.csv`.

To verify the integrity of the downloaded file, calculate its SHA-256 hash:

```bash
shasum -a 256 data/raw/datasets.csv
```

Compare the result with the `sha256` value recorded in `reports/data_overview.json`. The hashes should match if the file is identical to the dataset used to generate the report.

Keep the original CSV unchanged. If the hash differs, check the dataset source and download before proceeding.

## Data Inspection

Run the inspection script:

```bash
uv run python -m telco_churn.dataset
```

The script generates `reports/data_overview.json`, which records:

- Dataset dimensions and column data types
- Churn counts and proportions
- Duplicate customer IDs
- Missing and blank values by column
- Source file path and SHA-256 hash
- Python and pandas versions

The original CSV is read without modifying it.

## Reproducibility

The project uses `uv.lock` to lock dependency versions. The inspection report records the Python and pandas versions and the SHA-256 hash of the source CSV, allowing the dataset and execution environment to be identified.

To reproduce the report, use the same source dataset and run the inspection command in the configured environment.
